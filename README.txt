BRITNEY'S PORTFOLIO

Files:
- index.html: website sections and project descriptions
- style.css: strawberry matcha colours, layout and mobile styling
- script.js: six interactive JavaScript features

Preview:
1. Extract this ZIP.
2. Open index.html in a browser.
3. Test the welcome button, dark mode, project filters, mobile menu and copy-email button.
4. Resize the browser to check the mobile layout.

JavaScript features:
1. Welcome message
2. Light/dark theme toggle
3. Project category filter
4. Responsive mobile navigation menu
5. Copy email button
6. Automatically updated footer year

Important:
- Project descriptions are based on the uploaded assignment briefs. Please edit them if they don't match your actual implementation or personal contribution.
- Confirm your name, course and email before submitting.
- The contact link opens an email app. The copy button copies your email; the site does not send messages or store user data.
- Upload index.html, style.css and script.js to your GitHub Pages repository root. You do not need to upload this README unless you want it for your own reference.
- Submit the live website URL, not the ZIP file.
